# v0.1.0 — Native Windows milestone

First release of todotxt.rs, a Rust port of todotxt.net with a native Windows
interface and a portable frontend for Linux. This marks a usable, tested Windows
milestone. Full visual and behavioral parity is still being assessed.
The reference application is todotxt.net 3.3.1.0; this project uses independent
version numbers.

## Windows download

Download `todotxt-rs-v0.1.0-windows-x86_64.zip` from this release, extract it,
and run `todotxt-rs.exe`. No installer is required. Use File > Open to choose
your task file. On first launch the app uses a private copy of fictional demo
tasks; it reopens the last selected task file on subsequent launches.

The archive also includes the README, help, licenses and these release notes.
`SHA256SUMS.txt` contains the download checksum. Application preferences stay
in the user's configuration directory, independently of the extracted ZIP.

## Implemented

- Native Windows menus, editor, task list, status bar, Options and file dialogs,
  with resizing, wrapping, maximization and restoration.
- Task creation, editing, copying, completion, deletion, priorities, dates,
  eight sorts, grouping, filters and saved filter presets.
- Archive appending, tray minimization, close-to-tray, tray Exit and global
  Ctrl+Alt+M, font selection, calendar and optional debug logging.
- Native Windows printing and browser HTML preview, accepted by the maintainer
  as complete for this project.
- Preservation of task-file bytes where untouched, including UTF-8 BOM,
  line endings and blank lines. Writes are refused if the loaded source has
  changed externally; local drafts are retained for explicit recovery.
- Support for readable mounted files when final-path resolution is unavailable,
  including the tested rclone-mounted-file loading case.
- Archive destination selection in native Windows no longer shows a misleading
  overwrite confirmation. Choosing a path leaves existing contents unchanged.

## Validation and limits

Locally validated on Windows: formatting, 23 automated task/file tests, strict
Clippy, optimized build and the native GUI smoke check. The GUI check covers
archive selection without overwrite confirmation, exact preservation of its
existing bytes, resizing, task operations, dialogs, filters, printing-dialog
cancellation, tray controls and external-change refusal.

GitHub-hosted CI has not completed; Linux build/runtime validation remains
pending. This release includes a Windows x86-64 binary only. Linux users can
build from source using the README instructions.

Remaining differences include the original optional version notification,
exact WPF metrics and dialog behavior, and further visual/runtime comparison.
Linux tray/global shortcuts and full portable font-family/weight selection
remain incomplete. Physical printing and Explorer-restart tray recovery need
further validation. Donations and embedded print preview are excluded by
maintainer decision.

Future requests in `docs/BACKLOG.md`, including Ctrl+D, CLI task commands,
recurrence, OR filters, automatic conflict merging and mobile apps, remain
deferred. They are not features of this release.
