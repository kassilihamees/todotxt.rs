# v0.1.2-dev — Storage probe (diagnostic only)

This prerelease contains a standalone Windows x86-64 storage probe, not a new
GUI application release or a mounted-save fix. Saving through the affected
computer's rclone mount remains unresolved. Keep real task files backed up and
work on ordinary local storage during investigation.

Download/extract `todotxt-rs-storage-probe-windows-x86_64.zip` onto ordinary local
storage such as Downloads on C:, open PowerShell
in the extracted directory on the affected computer, and run:

```powershell
.\storage_probe.exe 'H:\todo'
```

The argument must be an existing directory. The program creates a uniquely
named subfolder and writes only new fictional files; it does not read or modify
an existing task file. It compares direct overwrite, the current application
save method, normal-file rename and Windows ReplaceFile, with immediate and
delayed byte checks. It takes about 40 seconds plus storage latency.

A report containing byte counts, comparisons and error codes is saved separately
in the local user data directory. Send that report and the affected machine's
rclone version/mount options, omitting credentials and account names. Do not
share real task/recovery contents. Test files are retained for inspection.

The ZIP includes the probe, instructions and BSD license; SHA256SUMS.txt contains
its checksum. Windows local-storage control and project checks passed. Results
from the affected computer are pending, and Linux runtime has not been tested.
The probe has no automatic write-method selection or live-file repair.
